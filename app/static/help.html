01第一次使用
  1. 新建文档管理器。登录后点击“＋ 新建文档管理器”；已有文档时，从顶部下拉框最下方新建。填写名称和腾讯在线表格地址，首次使用还需填写腾讯文档凭据。
  2. 选出要统计的同事。打开“设置 → 选择数据源”，选名单工作表、分布方向和范围，点击“保存数据源并读取名单”；勾选人员后点击“保存统计范围”。
  3. 告诉系统检查哪里。在“监听管理”中新建规则，选择工作表、责任人位置、填写区域和起止范围，保存并启用。
  4. 核对一次结果。有合并单元格时，先在设置中“刷新合并结构”，再回到“填写情况”点击“立即查询”。确认结果后打开“开启自动查询”。
  5. 需要提醒时再配置。请管理员配置发件邮箱，然后新建邮件模板。需要设备提醒时，将模板“设为主推送”，并在本设备的设置中打开“允许通知”。

顶部下拉框决定当前操作的文档。切换后，名单、监听规则、邮件模板和统计结果都会随之切换。

02查询与监听：谁还没填？
立即查询 / 开启自动查询
前者立即检查一次；后者让服务器按设置的间隔持续检查。关闭自动查询后，仍可手动查。关闭网页不会停止服务器的自动查询。
未填人数 / 未填条目
人数按姓名去重；同一条规则下，同一个人的多项未填任务合并显示。点击工作表名称可打开原表定位检查。
新增 / 编辑 / 启用 / 删除规则
新增、编辑用来配置检查区域；关闭“启用”会暂停该规则并保留配置；删除则移除规则。删除或改名后，检查引用该规则变量的邮件模板。
分布方式如何填写
列分布人员沿一列向下排列。例如责任人 A 列、检查 C,D 列、范围第 2–100 行。
行分布人员沿一行向右排列。例如责任人第 1 行、检查第 3,4 行、范围 B–Z 列。

同一任务选中的检查区域中，任意一格有内容即视为已填。责任人合并多行或多列时，整个合并范围算一项任务；该人在其他位置的空任务仍会计入。起止范围必须覆盖完整的合并区域。

系统用所选名单中的姓名匹配责任人文本，包括括号内文字。名单中的备注不会自动删除；请保持名单姓名与责任人写法一致，避免短姓名误匹配。

03设置：名单、合并单元格和通知
保存设置
保存文档管理器名称。文档地址为只读；需要改用另一张表时，新建文档管理器。
刷新工作表列表
重新读取可选的工作表。新建或改名工作表后使用；数据源和监听规则都通过下拉框选择工作表。
保存数据源并读取名单
保存姓名所在位置，并重新读取同事名单。名单变化后，再核对勾选范围。
全选 / 全不选 / 保存统计范围
前两个只改变当前勾选；点击“保存统计范围”才会生效。未勾选的同事不参与统计。
刷新合并结构
同步表格中的合并单元格位置。新增、拆分或调整合并区域后使用；只改文字不需要每次刷新。
允许通知
只控制当前设备。开启成功会提示“消息推送启动成功！”，关闭后停止本设备提醒；不改变邮件发送，也不关闭其他设备的通知。
高级设置 / 保存高级设置
调整自动查询间隔、连接超时，以及 Client ID、Open ID、Access Token。腾讯文档凭据由同一帐号下的文档共用；令牌失效后在这里更新并保存。
删除该文档管理器
删除本系统内该文档的配置、规则、模板和记录，不会删除腾讯文档原表。请先确认没有需要保留的内容。

所有完整时间按北京时间显示，格式为 yyyy-mm-dd hh:mm:ss。日期变量只含日期，时刻变量只含时分秒。

04邮件与通知：什么时候提醒？

点击“新建模板”，填写 1–5 个接收邮箱、邮件标题和正文。“添加接收人”和“移除”可调整邮箱数量；“保存模板”保存配置，“取消”退出编辑。邮件按纯文本发送，标题不能换行。

手动触发 / 发送邮件
保存后点击“发送邮件”。本页发送成功后按钮禁用，刷新可再次发送；5 分钟内重复触发会要求确认。“发送成功”表示发件服务器已接受，收件箱到达可能稍有延迟。
自动触发：每周几检查
选择一个或多个星期和当天开始时刻。仅在所选当天、到点后检查条件，当天结束停止；不补发过去检查日的邮件。每个检查日通常触发一次，下一检查日自动重新等待。
自动触发：固定时刻
填写完整日期和时间，例如 2026-10-09 18:00:00。从该时刻起等待条件满足；不会在当天结束时自动取消。
变量 / 关系 / 值
配置触发条件。例如“global.personcount → 大于 → 0”代表仍有人未填时提醒。可选整数或布尔变量；布尔值填写 true 或 false。
等待自动触发 / 重置自动触发
等待状态由系统检查，无需点击。完成或失败后可重置；如果时间和条件已满足，重置可能立即再发，先核实是否已经收到。
设为主推送 / 取消主推送
每个文档最多选一个模板，也可以不选。该模板触发时，通知显示替换变量后的邮件标题。不同文档独立选择；主推送不改变邮件的接收人或触发条件。

涉及未填人数或名单的自动模板，需要开始时刻之后的一次成功查询。建议同时开启自动查询。收到设备通知不等于邮件投递成功；发信失败时仍需查看模板状态。

设备接收提醒的条件
Windows 应用在设置中开启通知，关闭窗口后仍在托盘接收；托盘“退出”才结束。托盘还能打开页面、重新加载、更换网站和设置开机启动。
电脑网页允许浏览器通知，并保持至少一个页面打开；支持系统通知时会弹系统提醒。
iPhone 主屏幕应用先添加到主屏幕，再进入应用开启通知。系统需支持 Web Push，且服务已启用后台推送；普通 Safari 标签页只有页内提醒。
Android 网页 / 应用壳保持页面运行；支持系统通知时弹系统提醒，否则显示页内提醒。当前不支持关闭应用后的厂商后台推送。

首次开启不补发历史通知。Windows 休眠、断网或退出时不能实时接收，恢复后只补读仍在有效期内的消息。

05变量表：把实时结果写进邮件

变量表是当前文档的只读数据清单。“变量名”用于模板引用，“类型”决定能否比较或循环，“描述”解释用途，“值”是当前内容。点击“刷新变量”可重新读取；它不会代替“立即查询”去检查腾讯表格。

常用变量用途
global.personcount未填人数，可作为自动触发条件。
global.personlist
global.people		前者是逗号分隔的姓名文本，后者是供循环使用的姓名列表。
global.date
global.time
global.lastquery		当前日期、当前时刻、上次查询开始时间。
global.week.duration本周日期区间。preweek、postweek分别代表上周、下周；例如 global.postweek.monday 是下周一日期。
global.healthy1：结果有效；0：查询异常；2：正在查询；null：尚无有效结果。
global.listencount
global.listenenable		规则总数、已启用规则数。
listener1.personcount
listener1.personlist		某条规则的未填人数与姓名。listener1 要替换为该规则实际的变量名。
global.alllistener全部监听规则的列表，可逐条输出规则名称、未填名单等。

null 表示当前未知，不等于 0，也不等于没人未填。首次未查询、查询失败或规则未启用都可能出现未知值。邮件直接引用未知值时不会发送；先查询成功并核对数据。

06邮件语法与可复制示例

插入一个值

在标题或正文写 {{变量名}}，发送时替换为当前值。变量名区分大小写。合法引用显示蓝色，错误引用或语法会标红；红色模板可以保存，但不能触发。

【周报提醒】{{global.date}} 尚有 {{global.personcount}} 人未填写
本周：{{global.week.duration}}
尚未填写：{{global.personlist}}
请前往填写：{{global.url}}
上次查询：{{global.lastquery}}

逐个列出姓名

列表不能直接放进双花括号，使用 {% for 名称 in 列表 %} 遍历，最后用 {% endfor %} 结束。循环中的名称由你起名，只在对应循环内有效。

{% for person in global.people %}
• {{person}}
{% endfor %}

按规则分组，只列出已启用且有人未填的规则

{% for listener in global.alllistener with listener.enable == true and listener.personcount > 0 %}
{{listener.name}}：{{listener.personcount}} 人未填
{% for person in listener.people %}
• {{person}}
{% endfor %}
{% endfor %}

with 后写筛选条件，字段必须带循环名称前缀，例如 listener.enable == true。启用状态是布尔值，请用 true，不要写 1。

只遍历指定规则

将下例的 listener1、listener2 换成变量表中真实存在的规则名。

{% for item in [listener1, listener2] with item.enable == true %}
{{item.name}}：{{item.personlist}}
{% endfor %}
  • 比较支持 ==、!=；数字还支持 >、>=、<、<=。字符串用引号括起，如 listener.name == "本周进展"。
  • 用 and、or 和括号组合条件。类型必须匹配；筛选条件中的未知值会使该项跳过。
  • 循环最多嵌套 3 层。每个 for 都需对应一个 endfor，循环名称不能与已有变量冲突。
  • 不支持直接执行代码、函数、算术表达式或 if 标签；条件筛选放在循环的 with 后。
07帐号与管理

“记住密码”方便下次登录，“自动登录”允许会话到期后恢复登录；只在可信设备上开启。右上角“退出登录”会退出帐号并停止本设备通知。

普通用户
管理自己的文档、规则和邮件模板，没有“管理”入口。
管理员
可在“管理”中配置 SMTP，创建和管理普通用户。SMTP 是共用的发件设置，接收人仍由各邮件模板填写。
超级管理员
可管理用户权限。删除用户也会删除该用户的文档配置，请谨慎操作。

“保存 SMTP 设置”保存发件服务器、端口、加密方式、邮箱和授权码；具体参数按邮箱服务商提供的信息填写。“新建用户 / 编辑 / 保存用户”管理帐号；编辑时密码留空则保持原密码。用户名为 3–64 位字母、数字、点、下划线或短横线，密码至少 12 个字符。

08常见问题 FAQ
明明填了，为什么还显示未填？
先“立即查询”，再核对数据源勾选、责任人位置、检查区域和范围。调整过合并单元格时刷新合并结构；同一人的另一项任务为空，也仍会显示未填。
明明有人没填，为什么人数为 0？
确认规则已启用、同事已勾选并保存、姓名能匹配责任人。检查区域里任意一格有字即算已填，不会要求所选格子全部填满。
为什么显示“检查异常”、旧结果或 null？
当前数据尚不可靠。先检查文档访问权限和高级设置中的凭据，再查询一次。旧结果不代表此刻的填写情况，未知值不会被当作 0。
工作表列表读不到，或 Access Token 失效怎么办？
确认填的是腾讯在线表格地址，帐号有访问权限，三项凭据正确。令牌失效后重新获取并在高级设置保存；当前不会自动续期。然后刷新工作表列表。
到了时间，为什么自动邮件没发？
核对北京时间、所选星期、触发条件和模板提示。涉及未填数据时，先完成到点后的一次成功查询；模板标红、变量未知或已触发过本周期，也不会再次发送。
为什么“发送邮件”或“等待自动触发”不能点？
发送中、存在语法错误或本页已经发送成功时会禁用。自动模板由系统触发；已完成或失败后，核实邮箱再使用“重置自动触发”。
邮件显示成功但没收到？
检查接收地址、垃圾邮件和邮箱规则，稍等后再查看。成功表示发件服务器接受，不保证马上进入收件箱。提示发送结果不确定时，先核实再重发，避免重复。
打开了通知，为什么没有弹窗？
在当前设备的“设置 → 允许通知”中检查开关，并允许系统或浏览器通知。检查勿扰模式；Windows 应用需留在托盘，网页需保持运行，iPhone 后台提醒需从主屏幕应用开启。还要确认实际触发的是该文档的主推送模板。
通知有了，邮件却发送失败？
设备通知与邮件是两种提醒途径。查看邮件模板的错误提示，并请管理员检查 SMTP 配置；收到通知不能当作发信成功的凭据。
改了名单或规则，邮件模板突然标红？
变量名可能已被删除或改名。去变量表找当前名称，修正模板中的引用；红框的错误提示可帮助定位行列。
提示“已在其他页面修改”怎么办？
先保留未保存的文字，再刷新页面读取最新配置，然后重新编辑保存。
更新后界面没变化？Windows 要重装吗？
请维护者确认服务器已部署更新，再刷新网页或用 Windows 托盘“重新加载页面”。普通页面和业务更新通常不需要重装客户端；客户端自身功能变化才需要新安装包。
